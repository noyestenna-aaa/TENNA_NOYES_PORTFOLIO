# TENNA_NOYES_PORTFOLIO

A simple personal portfolio website for Tenna Noyes, published with GitHub Pages.

## Structure

- `index.html` — homepage
- `education.html` — education background page
- `work-experience.html` — experience page
- `writing-samples.html` — writing samples landing page
- `*.html` detail pages — project and writing sample entries
- `pdfs/` — production PDF assets used by the site

## Notes

The site uses the PDFs stored in `pdfs/` for the writing sample pages. The root-level PDF files and duplicate artifacts are not needed for the live site and should be removed if they are no longer part of the intended publishing workflow.

## Local preview

Open `index.html` in a browser, or serve the folder with a local static server if you want to test navigation and PDF embedding.
